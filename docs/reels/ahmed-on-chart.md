## 결론

이 계정에서 가장 구체적인 셋업은 **AVL(Accumulation–Volume Profile–Liquidity)**이다. 추세가 멈춘 횡보 범위에 fixed range volume profile을 적용하고, 범위 저점의 유동성 스윕 뒤 가격이 value area low(VAL) 위로 복귀할 때 매수한다. 손절은 스윕 저점 아래, 목표는 value area high(VAH)다. 같은 구조를 설명한 영상이 여러 번 반복 게시됐다.

그 밖의 내용은 anchored VWAP 재시험, 당일 고저점 스윕, 1% 고정 위험, 현실적인 2–3R 목표, order flow·CVD 확인, 거래 일지와 규칙 유지로 정리된다. 반면 “캔들 패턴·RSI·ICT는 가짜”, “안정적 월수익”, “60–70% 승률” 같은 주장은 검증 자료가 없어 전략 규칙으로 채택하지 않았다.

## 핵심 전략

### 1. AVL 범위 복귀 롱

1. 추세가 둔화하고 가격이 횡보하는 범위를 확정한다.
2. 범위 전체에 fixed range volume profile을 적용해 VAL과 VAH를 표시한다.
3. 가격이 범위 저점 아래의 유동성을 스윕할 때까지 기다린다.
4. 가격이 VAL 위로 다시 복귀하면 롱 후보로 삼는다.
5. 스윕 저점 아래를 무효화 지점으로, VAH를 1차 목표로 둔다.

횡보 확정 기간, 복귀 종가 기준, 숏 대칭 규칙, 거래 비용은 영상에서 충분히 정의되지 않아 백테스트 전에 추가 수치화가 필요하다.

### 2. Anchored VWAP 추세 재시험

상승 또는 하락 추세의 시작점에 VWAP을 고정하고 같은 방향의 되돌림 접촉을 진입 후보로 본다. 앵커 선정과 확인봉·손절·목표가 공개되지 않아 현재 상태로는 아이디어 수준이다.

### 3. 운영·위험 원칙

- 거래당 위험은 계좌의 1%를 상한 후보로 두되 변동성과 연속 손실에 맞춰 더 낮춘다.
- 단일 캔들, RSI 임계값이나 도구 이름만으로 진입하지 않는다.
- 10R 같은 과장된 목표보다 구조상 가능한 2–3R과 실제 체결비용을 평가한다.
- 손실 후 위험을 키우거나 전략을 즉시 교체하지 않고 동일 규칙의 표본을 쌓는다.
