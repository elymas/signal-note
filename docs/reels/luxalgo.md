## 접근 제한과 전수성의 경계

`agent-browser` 고유 세션 `luxalgo-reels`에서 공유 URL, 정식 데스크톱 URL, 모바일 URL을 반복 시도했다. 일반 페이지는 열렸지만 Facebook Reels 탭 탐색은 로그아웃 환경에서 약 27초 뒤 `about:blank`로 종료됐다. headed 모드, 새 탭, 모바일 URL과 타임아웃 확장으로도 DOM을 유지하지 못해 “페이지 높이와 고유 ID가 4회 연속 변하지 않음”이라는 무한 스크롤 종료 조건은 재현하지 못했다.

따라서 이 문서의 `40개`는 분석 시점에 확보한 후보 전부를 중복 제거하고, 각 원본이 LuxAlgo 게시물임을 개별 재검증한 수다. Facebook이 로그인 사용자에게만 추가로 노출하는 릴스, 지역·연령 제한 영상, 삭제·비공개 영상, 지연 로딩에서만 나타나는 항목이 전혀 없다는 플랫폼 수준의 보장은 할 수 없다. 이 제한을 숨기지 않기 위해 데이터의 `methodology.limitation`에도 같은 내용을 남겼다.
