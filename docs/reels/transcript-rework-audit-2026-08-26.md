## 메모형 카드 25편 복구와 한국어 편집 재검토

최근 감사에서 추가됐지만 `스크롤 끝에서 추가 확인된 공개 릴스`, `고유 ID를 연구 목록에 등록`처럼 수집 과정만 표시하던 25편도 별도로 원본을 다시 처리했다. LuxAlgo 1편, Erick Jablonski 2편, TradersNotes Jason 3편, Dumb Hunter 14편, Max Anthony 5편이다. 자동 자막 또는 로컬 Whisper 전사와 대표 프레임을 확보한 뒤, 각 영상의 실제 주장·실행 조건·누락 위험을 한국어 제목·핵심·규칙·검증 메모로 다시 편집했다.

최근 6개 채널 930편도 같은 기준으로 전수 재생성했다. 공개 카드에는 수집·스크롤·목록 등록·전사 과정 문구와 원문 전사 인용을 넣지 않고, 원본 제목만 별도 참고 필드로 유지했다. 생성 뒤 비한글 문자 혼입과 손상 문자를 ID별로 재검토해 한국어 편집본으로 교정했다. 이번 콘텐츠 품질 재검토 대상은 합계 955편이다.

생성 프롬프트에서 유래한 조건 오염도 별도로 감사했다. 카드의 제목·핵심·규칙·태그에 `오전 9시 30분` 또는 `1:2 위험보상비`가 있는데 원본 전사·게시 설명에는 해당 조건이 없는 ID를 전수 대조했고, 검출된 카드만 다시 생성했다. 재생성 뒤 최근 6개 채널의 근거 없는 수치 조건은 0편이다. 날짜와 영상 길이의 `00:12` 같은 표기를 위험보상비로 오인하지 않도록 의미 필드만 검사한다.

음성·게시 설명을 합쳐도 24자 미만인 28편(20-Minute Trader 19편, Raghee Horner 9편)은 모델 추론을 사용하지 않고 대표 프레임 시트를 전수 판독했다. 화면 문구와 장면을 근거로 밈·동기부여·기초 용어·비전략 자연 영상으로 다시 편집했으며, 근거가 없던 반복형 `15분 거래 전략` 요약은 제거했다.

Raghee Horner의 2편은 원본 포맷에 음성 스트림이 없었다. 한 편은 화면 내 자막이 있는 동기부여 영상이고 다른 한 편은 천문 영상이므로, 게시문 캡션과 전 구간 대표 프레임을 근거로 `전략 아님` 범위에서만 기록했다.

yostrades와 Trade with Pat에서도 각각 1편은 원본에 음성 스트림이 없어 게시문 캡션과 대표 프레임으로만 범위를 제한해 기록했다.

20-Minute Trader의 45–57분 라이브 5편은 Facebook 자동 자막이 편당 158–218단어에 그쳐 불완전했다. 해당 자막을 폐기하지 않고 감사 비교 자료로 남기되, 사이트 분석에는 전체 오디오를 다시 전사한 편당 6,097–10,507단어의 Whisper 결과를 우선 적용했다. 파이프라인도 5분 이상 영상에서 자동 자막 밀도가 분당 40단어 미만이면 로컬 전사로 자동 전환하도록 보강했다.

## 적용한 분석 절차

1. Aside 인증 세션에서 각 Facebook Reels 탭을 끝까지 스크롤해 확보한 고유 URL 인벤토리를 기준으로 삼았다.
2. `yt-dlp`로 원본 메타데이터, 자동 자막, 썸네일을 수집했다.
3. 자동 자막이 없으면 오디오를 내려받고 `mlx-community/whisper-large-v3-turbo`로 로컬 전사했다.
4. 각 영상의 전 구간을 일정 간격으로 샘플링한 5×4 대표 프레임 콘택트시트를 만들었다.
5. 전사·캡션·화면을 대조해 영상별 핵심 발화, 실행 문장, 성과 주장, CTA, 누락된 손절·청산·포지션 크기·거래비용을 상세 노트로 분리했다.
6. 사이트에는 원문 전체를 복제하지 않고 전사 출처와 단어 수, 근거 문장, 위험 검토 결과를 저장했다. 전체 전사와 프레임 시트는 로컬 감사 산출물로 보존한다.
