## 적용한 분석 절차

1. Aside 인증 세션에서 각 Facebook Reels 탭을 끝까지 스크롤해 확보한 고유 URL 인벤토리를 기준으로 삼았다.
2. `yt-dlp`로 원본 메타데이터, 자동 자막, 썸네일을 수집했다.
3. 자동 자막이 없으면 오디오를 내려받고 `mlx-community/whisper-large-v3-turbo`로 로컬 전사했다.
4. 각 영상의 전 구간을 일정 간격으로 샘플링한 5×4 대표 프레임 콘택트시트를 만들었다.
5. 전사·캡션·화면을 대조해 영상별 핵심 발화, 실행 문장, 성과 주장, CTA, 누락된 손절·청산·포지션 크기·거래비용을 상세 노트로 분리했다.
6. 사이트에는 원문 전체를 복제하지 않고 전사 출처와 단어 수, 근거 문장, 위험 검토 결과를 저장했다. 전체 전사와 프레임 시트는 로컬 감사 산출물로 보존한다.
